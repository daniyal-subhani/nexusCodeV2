# Drizzle + MySQL

## Generate

### SQL file banata hai (schema se)

```
pnpx drizzle-kit generate
```

```
npx drizzle-kit generate
```

```
pnpm drizzle-kit generate
```

## Migration

### SQL file DB pe chalta hai + history maintain karta hai

```
pnpx drizzle-kit migrate
```

```
npx drizzle-kit migrate
```

```
pnpm drizzle-kit migrate
```

## Push

### Seedha schema DB pe apply karta hai (file nahi banata)

```
pnpx drizzle-kit push
```

```
npx drizzle-kit push
```

```
pnpm drizzle-kit push
```

### Check Live

```
pnpx drizzle-kit studio
```

```
npx drizzle-kit studio
```

```
pnpm drizzle-kit studio
```
